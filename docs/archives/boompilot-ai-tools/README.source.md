# BoomPilot AI Tools

这是我的个人 AI 工具目录，用来保存 BoomPilot AI 工具箱发现的可视化、可本地部署的 GitHub 项目。

目标不是收集所有热门仓库，而是优先整理这些类型：

- 有可视化 Web UI
- 适合本地部署或自托管
- 对中文用户有实际用途
- 能接入 BoomPilot AI Toolbox 做一键安装、启动、日志和健康检查

当前目录：

- [中文工具目录](ai-tools/catalog.md)
- [结构化仓库清单](data/repositories.json)

说明：

- 本仓库是个人整理，不是 GitHub 官方、OpenAI 官方或任何项目方官方推荐。
- 安装前仍应先做安全审查，尤其是包含 Docker、安装脚本、远程下载脚本、API Key 或浏览器自动化能力的项目。
- API Key、token、secret 不应提交到本仓库。
